# 区域级证据锚 —— 坐标系/旋转核验记录（T-P0-3 验收闭环）

> 本文是 v1.1.1 中 T-P0-3 唯一未闭合验收项 ——"抽 5 页人工核对高亮框与页面坐标系
> 一致" —— 的闭环记录。结论：**已闭环**（算法/数据/方向三层各自有独立证据），
> 并附一条**负面结论**：本批记录上不存在廉价的像素代理判据，故不写伪测试。
>
> 复算入口：`scripts/verify_region_anchor.py`（本机可视化）、
> `scripts/verify_anchor_orientation.py`（方向独立核验）、
> `tests/unit/test_anchor_orientation_tool.py`（核验工具自身的单测）。

---

## 1. 开放项为什么"验不了"

离线的确定性单测能证明**算法与数据**正确：

* bbox 归一化必然落在单位方格（`normalize_bbox` 是唯一出口）；
* 坐标系被如实记录（`space` / `space_aspect` / `space_rotation`）；
* SSR 与 AJAX 共用同一个 `region_anchor`（不会两处不一致）。

但它们**证明不了**"人眼看到的框位置对不对"。而这一项又恰恰是复合风险点：
51 页里有 1 页（第 8 页）坐标系与服务端不同源 —— Paddle 上报
`doc_preprocessor_res.angle = 270`，把该页转正后才做版面检测，于是
`prunedResult.width/height` 是 `1920×1440`（横向），而页面是竖向。
**若不逆映射就直接叠加，框会整体横竖颠倒。**

所以开放项的本质不是"跑一遍看看"，而是：**能否证明逆映射的方向是对的。**

## 2. 三层证据（各管一件事，互不替代）

| 层 | 证明什么 | 手段 | 可复现 |
|---|---|---|---|
| A. 确定性单测 | 映射**表**与**语义** | `tests/unit/test_regions_anchor.py`：四旋转精确值、四次 90° 成组回原点、面积守恒、未知角 → `None`；真实产物地标落点 | ✅ 只需产物 jsonl |
| B. 独立地面真值 | 映射**方向**（0/270 谁对） | `scripts/verify_anchor_orientation.py`：配准上游回传的两张图 | ✅ URL 无过期（授权串 `/-1/`） |
| C. 本机可视化 | 人眼**抽查**框落位 | `scripts/verify_region_anchor.py`：生产函数算框 → 画到真实渲染页 | ✅ 只需产物 + PyMuPDF |

### A. 语义与几何不变量（无像素）

逆时针旋转 θ 的逆映射（`(u,v)` 为 OCR 空间归一化坐标）：

| rotation | 页面空间 |
|---|---|
| 0 | `(u, v)` |
| 90 | `(1-v, u)` |
| 180 | `(1-u, 1-v)` |
| 270 | `(v, 1-u)` |

由**不变量**独立推出（不是从产物"反拟合"）：四条互逆、四次 90° 回到原点、
面积守恒、轴对齐矩形不被撑大 —— 均由单测钉死。

方向由**结构语义**钉死：第 8 页映射后，公司 logo（`HISUN 海正药业`）与
`文件编号：H3-MPD-10133-R21` 落在**左下**，`页码：5/24` 落在**右上**，
与渲染图逐点核对一致（`test_real_rotated_page_landmarks_land_where_they_should`）。
若方向判反，这三个地标会整体镜像到对侧，用例立刻失败。

### B. 独立地面真值（决定性）

Paddle 在响应里回传两张图，二者构成可实测的链条：

```
页面图 ──ρ──▶ inputImage（未旋转） ──θ──▶ layout_det_res（bbox 所在坐标系）
```

`outputImages.layout_det_res` 是 **Paddle 自己**在"旋转后 + 画好检测框"的图上渲染的
可视化 —— 即"它实际用于版面检测的那个坐标系"，与我们的代码完全无关。

实测（`--pages 3,7,8,9,19,35`，命中率领先异轴候选的比值即"轴优势"）：

| 页 | 上报角 | ρ 轴 | θ 轴 | θ 实测 | 轴优势 | 方向 | 判定 |
|---|---|---|---|---|---|---|---|
| 3 | 0 | 0 | 0 | 0 | 18.93× | 可分辨 | PASS |
| 7 | 0 | 0 | 0 | 0 | 2.65× | 可分辨 | PASS |
| **8** | **270** | **0** | **90** | **270** | **3.15×** | **可分辨** | **PASS** |
| 9 | 0 | 0 | 0 | 0 | 2.41× | 可分辨 | PASS |
| 19 | 0 | 0 | 0 | 0 | 3.17× | 可分辨 | PASS |
| 35 | 0 | 0 | 0 | 180 | 1.78× | 不可分辨 | PASS-AXIS |

两条关键读数：

1. **ρ 轴恒为 0** —— 喂进模型的图与渲染页同向（`inputImage` 与页面墨迹在 0°
   下 100% 重合）。这是整条链成立的前提，已实测。
2. **第 8 页 θ = 270°，与上报角一致，且方向可分辨** —— `map_bbox_to_page(bbox, 270)`
   的逆映射方向由此被**独立证实**，不是靠直觉。

> 第 35 页标 `PASS-AXIS`：轴（横竖）已证实，但该页是密排表格，内容在 180° 下近乎
> 自对称，**方向不可分辨**。工具如实报告，而不是硬给一个胜者 —— 见 §3。

### C. 本机可视化抽查

`scripts/verify_region_anchor.py --pages 3,7,8,19,35 --induce-naive`
把每个区域按**页面空间**画到真实渲染页（红=锚中，蓝=其余），并对旋转页额外输出
一张"不做逆映射"的对照图（旋转页上必然错位）。产物：
`devlogs/region_anchor_check/{p03,p07,p08,p19,p35}.jpg`、`p08_naive.jpg`、`report.json`。
（该目录被 gitignore：图源自真实批记录，不入库。）

机检项（5 页全 PASS）：区域可映射到页面空间、结果不越出单位方格、探针必被锚中、
`page_aspect` 与渲染图实际宽高比一致（容差 2%）。

## 3. 负面结论：为什么**不**写"像素自校准"测试

"抽 5 页目视"不可复现，直觉上会想把它换成一条机检。本批记录上实测了四种候选判据，
**全部不具鉴别力**（判据让"记录角度=最优"成立的比例）：

| 候选判据 | 实测一致率 | 失效原因 |
|---|---|---|
| 框内墨迹**密度**均值 | **58.8%**（30/51） | 框落到任何密排区域都会得高分；表格页尤其严重 |
| 全页/框内**投影空白带**奇偶 | 不可用 | 第 3 页（竖向页、`rot=0`）即被误判为"横向内容" |
| 框内**文本行方差差** | **12.0%**（6/50） | 紧致框只有几十像素，噪声压倒信号 |
| 整页**区域并集 F1** | **29.4%**（15/51） | 大表格框本来就覆盖全页，四种旋转差异在噪声内 |

**故刻意不把这些判据写成测试。** 一个"永远绿、其实不具鉴别力"的测试比没有测试更糟：
它会把"未验证"包装成"已验证"。真正有鉴别力的是 §2B（独立地面真值）与 §2A
（结构语义地标）—— 前者是对的，后者是确定性的。

同一条原则也体现在核验工具的**诚实分级**（`tests/unit/test_anchor_orientation_tool.py`
用合成图案把这两级都钉住了）：

* 轴判错 = **FAIL**（框会横竖颠倒，唯一致命的失败模式，硬拦）；
* 同轴内方向分不清 = `PASS-AXIS`（**如实认怂**，不伪造 PASS）。

## 4. 已知限制与残余风险

1. **去畸变残差（非旋转所致）**：Paddle 前处理开了
   `use_doc_unwarping: true`，块 bbox 与渲染图之间存在随位置变化的非刚性形变。
   已实测对比证明该残差**不是旋转引入的**（未旋转页同样存在），且第 8 页经逆映射后
   的对齐质量反而最优。影响面：高亮框可能比文字略松 —— 这与"只做到区域级"的
   产品口径一致（Paddle/MinerU 都不回传单元格级 bbox，见
   `docs/NOISE_REDUCTION_SPIKE.md`），我们不宣称单元格级。
2. **`PASS-AXIS` 页**：密排表格页在 180° 下近乎自对称，工具无法分辨同轴内的方向。
   这些页上报角均为 0、轴已证实，**转置不可能发生**；但若将来出现真正 0/180 存疑的
   页面，需按 §2A 的地标语义另行判定。
3. **上游能力依赖**：旋转逆映射完全依赖 `use_doc_orientation_classify` 开着。
   一旦上游关掉，`angle` 会变 `-1` → 我们归 `None` → 旋转页静默退回宽高比闸门
   （"无法定位"，不是崩溃）。这是**能力退化**而非报错，最难察觉 —— 已由
   `test_real_artifact_reports_orientation_for_every_page` 钉死。
4. **建议的后续加固（未实施，属独立改动）**：stage1 落库时把上游回传的
   `layout_det_res` 一并留存，则 §2B 的校准可以**完全离线**重跑（目前依赖上游 URL
   长期有效；实测授权串为 `/-1/` 无过期，但那是上游的承诺，不是我们的保证）。

## 6. 结论

* **T-P0-3 的"抽 5 页人工核对"已闭环**：不再是"谁看了说对"，而是
  ①确定性不变量（A）②独立地面真值实测方向（B）③可归档的可视化证据（C）。
* 第 8 页的旋转逆映射方向**已被独立证实为 270°CCW**，与上报角一致；
  其"框不套字"的观感来自上游去畸变残差，而非映射错误。
* 本批记录上**不存在**廉价的像素代理判据（§3），故不写伪测试 —— 这一条负面结论
  本身就是本次调研的产出，避免后人重复踩坑。
