【什么是便携版】
BatchSentry 便携版是一个文件夹形式的分发包（win-unpacked），
无需安装，双击 BatchSentry.exe 即可运行。
所有配置和数据存储在用户目录（%APPDATA%\PBC\），不会污染系统。

------------------------------------------------------------
【首次运行步骤】
------------------------------------------------------------

1. 双击 win-unpacked\BatchSentry.exe 启动程序
   - 首次启动需要 5-15 秒（初始化数据库 + 加载 Python 运行时）
   - 启动过程中会显示启动进度

2. 首次进入后，页面会显示黄色提示：
   "尚未配置 LLM 服务商"
   点击"设置页面"进入配置

3. 在设置页面配置至少一个 LLM 服务商：
   - 内置支持：DeepSeek、SiliconFlow
   - 也可添加：GLM、Kimi、Qwen、MiMo、Anthropic Claude
   - 必填：API Key（其他字段有默认值）
   - 点击"测试连接"验证配置是否正确

4. （可选）配置 OCR 服务（建议同时配置，启用主备 failover）：
   - 主后端：由 OCR_BACKEND 决定（PaddleOCR-VL 或 MinerU，需配置 Token）
   - 备后端：另一个后端（配好即自动作为备选）
   - 主后端异常/0 页/缺页超过 20% 时自动切换，无需人工干预
   - 实际使用后端记录在任务详情（ocr_backend_used），可追溯
   - 无 OCR 配置则无法处理 PDF

5. 返回首页，上传 PDF 批生产记录开始分析
   - 支持 PDF 最大 200MB，并发处理 3 个任务
   - 任务状态实时流式更新（OCR 页数、分析页数、findings 数）

------------------------------------------------------------
【配置文件位置】
------------------------------------------------------------

便携版的所有配置和数据存储在：
  Windows: %APPDATA%\PBC\
    ├── config.json       # 配置文件（API Key、服务商、OCR 后端等）
    ├── data.db           # SQLite 数据库（任务记录、findings、审计日志）
    └── output\           # 输出目录（PDF 文件、临时文件）

配置请通过程序内的"设置页面"修改（保存后立即生效，无需重启）。
如需手动编辑，请编辑 %APPDATA%\PBC\config.json
（注意：必须为 UTF-8 无 BOM 编码，否则程序无法解析）。

【常见问题】
------------------------------------------------------------

Q: 启动时提示"端口 58765 已被占用"？
A: 另一个 BatchSentry 实例正在运行。请通过任务管理器
   结束 pbc-server.exe 进程后重试，或关闭其他 BatchSentry 窗口。

Q: 启动后页面空白？
A: 后端服务启动超时（>30秒）。常见原因：
   - 杀毒软件拦截了 pbc-server.exe（请添加信任）
   - 系统资源不足（建议至少 4GB 可用内存）
   - 数据库损坏（删除 %APPDATA%\PBC\data.db 后重启）

Q: 上传 PDF 后一直显示"OCR识别中"？
A: 检查 OCR 服务配置是否正确。在设置页面点击"测试连接"。
   配置了主备双后端时，主后端失败会自动切换备后端重试。

Q: LLM 分析很慢？
A: 51 页文档默认并发 5 页，约 10-15 分钟完成。
   可在设置页面调整 LLM 并发数（注意 API 速率限制）。
   DeepSeek 默认 50 RPM，建议保持 5-10。

Q: 如何备份数据？
A: 复制整个 %APPDATA%\PBC\ 目录到备份位置即可。
   恢复时将备份目录覆盖回 %APPDATA%\PBC\。

Q: 如何完全卸载？
A: 1. 删除整个 win-unpacked 文件夹
   2. 删除 %APPDATA%\PBC\ 目录（包含所有数据和配置）

------------------------------------------------------------
【安全说明】
------------------------------------------------------------

- 本程序仅在 127.0.0.1 本地监听，不会暴露到网络
- API Key 存储在 %APPDATA%\PBC\config.json（明文，请勿在共享电脑使用）
- 上传的 PDF 文件存储在 %APPDATA%\PBC\output\，删除任务时一并清理
- 所有状态转换记录在 audit_log 表，可用于 GMP 合规追溯
- LLM 调用记录在 llm_call_audit 表（含 provider/model/token 用量）

【技术支持】
------------------------------------------------------------

- 日志文件位置：%APPDATA%\PBC\logs\（如已配置）
- 控制台输出：开发模式下可在 DevTools 查看（Ctrl+Shift+I）
- 问题反馈：请附上日志文件和重现步骤
