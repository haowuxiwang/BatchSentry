LLM 大模型

用于批记录结构化分析与问题发现

OCR 文档解析

将 PDF 批记录转换为结构化文本

pipeline=通用解析（默认）；vlm=精度更高（推荐）；MinerU-HTML=HTML 结构输出，左侧 OCR 原文以 HTML 表格展示，适合批记录。

默认官方地址；私有化部署 / 代理场景可覆盖，留空即恢复默认。

每片 N 页：>1 时启用流式——一片 OCR 完成立即开始该片页面 LLM 分析， 边处理边出结果，无需等全部页 OCR 完成。默认 1（整份一次提交）。

合规规则

用户自定义规则注入跨页 LLM 分析 0 条

填写工厂/产品专属合规约束（如「XX 产品中间体储存温度必须 15-25°C」「关键工序必须双人复核签名」）， 跨页分析时注入 LLM 逐条核对，命中后生成 user_rule 类型的问题。留空可跳过此项。

飞书通知

任务完成/出错时推送摘要，通知失败不影响任务处理

接入步骤（自建应用私聊）
  1. open.feishu.cn 创建企业自建应用
  2. 启用「机器人」能力
  3. 开通权限 im:message（发消息）+ contact:user.id:readonly（按手机号查 open_id）
  4. 创建版本并发布（自己管理时默认免审）
  5. 在「API 调试台」调 contact/v3/users/batch_get_id 填自己手机号复制 open_id

open_id 与应用绑定，换应用需重新获取。

在飞书群「设置 → 群机器人 → 添加机器人 → 自定义机器人」创建 Webhook， 可选勾选签名校验。仅发送到机器人所在群。

每个 LLM 提供商的 API Key、协议、Base URL、模型请在对应卡片内点击「保存」一次性提交（即时生效，首次保存会自动设为当前）。底部"保存全部设置"用于 OCR 与飞书通知等通用字段。 "测试连接"会并行检测 OCR + 所有已配置的 LLM 提供商。
