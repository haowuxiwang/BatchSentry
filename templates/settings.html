填写工厂/产品专属合规约束（如「XX 产品中间体储存温度必须 15-25°C」「关键工序必须双人复核签名」）， 跨页分析时注入 LLM 逐条核对，命中后生成 user_rule 类型的问题。留空可跳过此项。

飞书通知

支持两种通道：自建应用私聊（推荐，机器人私信你本人）或群机器人（发送到群）。 任务完成/出错时推送摘要。通知失败不影响任务处理。

接入步骤：open.feishu.cn 创建企业自建应用 → 启用「机器人」能力 → 开通权限 im:message（发消息）＋ contact:user.id:readonly（按手机号查 open_id）→ 创建版本并发布（自己管理时默认免审）→ 在「API 调试台」调 contact/v3/users/batch_get_id 填自己手机号复制 open_id。 open_id 与应用绑定，换应用需重新获取。

在飞书群「设置 → 群机器人 → 添加机器人 → 自定义机器人」创建 Webhook， 可选勾选签名校验。仅发送到机器人所在群。

每个 LLM 提供商的 API Key 请在对应卡片中独立保存（即时生效，首次保存会自动设为当前）。 此处"测试连接"会并行检测 OCR + 所有已配置的 LLM 提供商；"保存通用设置"仅保存 OCR 后端切换、模型选项等通用配置。
